PronunciaCoach TM

Entrenador de pronunciacion en ingles - modelo Teachable Machine Audio + audios nativos desde la web - 100% en el navegador

Elige modo

Modo Rapido (SR Web)
Arranca al instante. Usa el reconocimiento de voz nativo del navegador (Web Speech Recognition API con el motor de Google) + audios nativos de Dictionary API. Funciona para cualquier palabra en ingles.
Sin descargas ni configuracion.
Modo Personal
Entrena tu propio modelo TM Audio con las palabras que tu quieras (pares minimos dificiles: ship/sheep, think/sink...).
Requiere entrenamiento previo en teachablemachine.withgoogle.com.
Modo Demo
Simula predicciones sin micro ni modelo. Para presentar el flujo si falla el equipo.
Como funciona: la app usa el modelo speech-commands de Google (la misma tecnologia detras de Teachable Machine Audio) para reconocer lo que dices, y descarga la pronunciacion nativa de cada palabra desde la Dictionary API (api.dictionaryapi.dev). El audio tuyo nunca sale del navegador.
