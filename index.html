Entrena tu pronunciacion en ingles con tu propio modelo de Google Teachable Machine (Audio) - 100% en el navegador

1. Configurar modelo

Pega la URL que te dio Teachable Machine al exportar tu modelo Audio (TensorFlow.js -> Upload my model). Debe tener 3-6 palabras objetivo + la clase Background Noise que TM agrega sola.

Sugerencia: para hispanohablantes, los pares minimos mas utiles son:
- ship / sheep (i corta vs larga)
- think / sink (th vs s)
- very / berry (v vs b)
- road / load (r vs l)
Tip exposicion: si falla la red o el modelo no carga, el Modo demo simula predicciones y permite mostrar el flujo completo.
